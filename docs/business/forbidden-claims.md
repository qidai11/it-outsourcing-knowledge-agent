# Forbidden Claims

> 版本：v0.1  
> 用于项目文档、演示、汇报和简历的真实性门禁。

## 1. 当前绝对禁止声称

在未真实实现或实测之前，禁止写：

- “已接入公司生产 Jira / 禅道 / 飞书项目”；
- “已用于真实客户生产项目”；
- “已支撑线上用户/线上 QPS”；
- “生产跨项目泄漏为 0”；
- “准确率达到 xx%”；
- “节省 xx% 人力/工时”；
- “客户满意度提升 xx%”；
- “处理 xx 万份真实客户文档”；
- “实现 SaaS 多租户”；
- “实现客户计费/Budget Guard”；
- “AI 自动判定重复工单”；
- “AI 自动发布正式文档”。

## 2. 当前允许的准确表述

可以写：

- “基于两个模拟/脱敏项目构建项目级隔离测试”；
- “设计并实现 SandboxProjectTrackerAdapter，用于验证工单查询、草稿、确认、幂等与故障恢复”；
- “以 P0 回归集验证跨项目 Evidence/Citation 泄漏”；
- “目标指标为……，最终结果以评测报告为准”；
- “预留项目级 Token/OCR/检索轮次/估算成本埋点”；
- “V1 定位 internal-first, external-ready，客户 Guest 与 SaaS 化属于路线图”。

## 3. 指标表述规则

### 未评测

写：

```text
验收目标：Exact-Identifier Hit@10 ≥ 95%
```

不能写：

```text
Exact-Identifier Hit@10 达到 97.6%
```

### 已使用模拟数据评测

写：

```text
在模拟回归集（n=XX）上达到……
```

不能省略“模拟”。

### 已使用脱敏真实数据评测

必须说明：

```text
在公司授权脱敏回归集（n=XX）上……
```

同时保留可复现评测脚本和报告。

## 4. 简历门禁

简历中每个量化数字必须能够回答：

1. 数据来自哪里？
2. 样本量是多少？
3. 如何划分？
4. 评测脚本在哪里？
5. 是否真实生产流量？
6. 是目标、模拟结果还是脱敏真实结果？
7. 个人具体负责哪部分？

无法回答则不得写入。
